# MS Tech — Projeto Web

## Como abrir no VS Code
1. Extraia a pasta `MS-TECH`.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.
4. Para acessar o painel, clique em **Área Administrativa**.

## Login de demonstração
- Usuário: `maison`
- Senha: `1234`

## Recursos
- Site responsivo
- Serviços gerenciados pelo painel
- Cadastro/exclusão de serviços
- Formulário de solicitação de atendimento
- Armazenamento local no navegador (`localStorage`)
- Filtro de solicitações por data e serviço
- Login administrativo de demonstração

## Importante
Este projeto é uma base front-end. O login e os dados usam `sessionStorage`/`localStorage`, portanto não devem ser usados em produção para dados reais. Para produção, substitua por backend, banco de dados, autenticação segura e HTTPS.
